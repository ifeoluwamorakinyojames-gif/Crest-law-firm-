ADMINISTRATOR ACCESS

Manage your account password

This website's Decap CMS uses individual GitHub accounts to authorize content edits. Your password is managed securely by GitHub, not by this website or its public source code.

Change your GitHub password

Sign in to the GitHub account that has edit permission for Crest Crown Attorneys. In GitHub's Password and authentication settings, enter your current password and a strong replacement.

Open GitHub password settings ↗

Password changes take place only on GitHub. We never ask you to type a password on this page, and this website does not store passwords.

Protect administrator access

  • Use a unique password and enable two-factor authentication.
  • Give each administrator their own GitHub account and appropriate repository permissions.
  • Do not reuse an initial shared password or put it in source code or browser storage.
  • Keep publication approval with an authorized reviewer.
Development status: The Decap CMS GitHub OAuth integration still needs its approved authentication service configured. Changing your GitHub account password does not enable the CMS by itself. Read setup instructions.
